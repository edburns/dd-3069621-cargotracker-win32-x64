````
special Copilot reviewer token. This is a local capability preflight and must

```bash

  GH_PR_EDIT_HELP_STATUS=0

  echo "SHEPHERD FAILED: could not inspect gh pr edit capabilities; gh exited $GH_PR_EDIT_HELP_STATUS."

*'@copilot'*)
````
