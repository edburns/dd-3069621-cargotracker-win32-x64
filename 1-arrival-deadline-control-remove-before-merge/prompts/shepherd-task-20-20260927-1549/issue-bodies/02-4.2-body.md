The resolved facade contract is `void changeDeadline(String trackingId, Date arrivalDeadline)`. Convert only the identifier with `new TrackingId(trackingId)` and pass the same `Date` to the application service. Domain types such as `Cargo`, `TrackingId`, and `RouteSpecification` must not cross into the JSF-facing API, and no command DTO or formatted-string service parameter is warranted.

Research on the prepared baseline established that test sources compile in the JDK 17 Open Liberty package build but the historical remote Arquillian suite remains skipped by default. A container-free facade test may use a hand-written fake; do not add a mocking library or modernize the runtime.

## Implement

Modify:

- `src/main/java/org/eclipse/cargotracker/interfaces/booking/facade/BookingServiceFacade.java`
- `src/main/java/org/eclipse/cargotracker/interfaces/booking/facade/internal/DefaultBookingServiceFacade.java`

Optionally add:

- `src/test/java/org/eclipse/cargotracker/interfaces/booking/facade/internal/DefaultBookingServiceFacadeTest.java`

Add:

```java
void changeDeadline(String trackingId, Date arrivalDeadline);
```

Delegate exactly once:

```java
bookingService.changeDeadline(
        new TrackingId(trackingId),
        arrivalDeadline);
```

Keep the facade as a boundary adapter. It must not load or mutate a cargo, call the repository, parse date strings, enforce a new chronological rule, or introduce JSF/PrimeFaces types. Preserve the same `Date` value/object through delegation and use the application service implemented in task 1.

If practical in this codebase, add a container-free JUnit test with a hand-written `BookingService` fake or spy proving:

- the tracking string becomes an equivalent `TrackingId`;
- the same deadline reaches the application service;
- delegation occurs exactly once;
- no repository behavior is duplicated.
